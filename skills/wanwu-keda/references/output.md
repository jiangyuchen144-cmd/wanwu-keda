# 动态输出

输出由问题决定，不由模板决定。**没有固定模块数、固定字数、固定盲点数、固定学科数。**

## 1. 三种模式

| 模式 | 输出目标 | 典型形态 | 禁止 |
| --- | --- | --- | --- |
| 快速 | 让用户立即得到可靠答案 | 一两段：答案 + 依据 + 条件 | 十段结构、学科清单、追溯附录、硬造盲点 |
| 标准 | 让用户理解关键机制与争议 | 若干必要块，按逻辑排列 | 为凑块写空话；默认跨学科 |
| 深度 | 让用户能核对重要判断 | 完整分析 + 重要结论追溯 + 审查修正 | 用长度冒充深度；把所有模块都写满 |

用户说「快速」「标准」「深度」「只给结论」「展开」时，按用户要求切换；用户要求与问题风险冲突时，先满足安全/准确性，再说明。

## 2. 快速模式

### 2.1 结构

1. **答案**：直接回答。
2. **依据**：一条最关键的理由/事实/来源。
3. **条件**：在什么范围内成立。
4. **可选的一句改口**：如果你问的其实是 X，告诉我。

通常一两段；内容需要时可以更短或稍长。不要写「以下是分析」。

### 2.2 示例

> 1+1=2 不是经验发现，而是自然数算术的定义与公理推出的结果。在皮亚诺公理中，2 定义为 1 的后继，加法定义为「a+0=a，a+S(b)=S(a+b)」，所以 1+1=2。若换一套非标准算术或不同的符号约定，这句话的含义会变；但在通常算术中，它是定义内的必然结论。

这已经够了。不需要学科矩阵、盲点、竞争解释、追溯附录。

### 2.3 何时不适用快速

- 关键事实不确定，或需要最新数据。
- 问题含价值冲突，不只是事实。
- 用户要做高风险决定。
- 问题本身有错误前提，需要先纠正。

## 3. 标准模式

### 3.1 可选块

按需选择，不必全用，也不必按固定顺序：

- **答案先行**：一句话结论，标性质与证据状态。
- **问题界定**：这题真正问什么；混合问题拆开；错误前提纠正。
- **关键事实**：只列承重事实，标时间、范围、证据状态。
- **机制/解释**：因果链、条件、量级、时间尺度。
- **竞争解释**：只列真实竞争者，给区分性观察。
- **盲点**：只列有证据的，标四态；可为空。
- **边界与不确定**：缺什么、哪些不能由证据回答。
- **结论与下一步**：分层结论；什么会改变判断。

### 3.2 组装规则

- 先写答案，再写理由；不要先铺陈背景。
- 每个块必须有实质内容；没有就删。
- 标题自然，不必用「模块一」。
- 一个块能说清就不要拆成三个。
- 引用学科时写它提供了什么工具/变量，不写「从 X 学科看」。
- 重要事实/因果/建议用内联追溯；不需要完整表。

### 3.3 标准模式的最小形态

有些问题只需要：

> 答案（信息性质/证据状态）
> 关键事实（有几条写几条）
> 真实存在的竞争解释（可以没有，或只有一个）
> 一句边界

这比五段空话好。

## 4. 深度模式

### 4.1 内容

深度模式不是固定十段，而是确保十阶段都真的跑过。输出可以合并阶段：

- 问题界定 + 关键前提
- 基础事实 + 证据缺口
- 领域选择（只写实际用到的）
- 机制 + 竞争解释 + 反证
- 盲点审计
- 分层结论
- 追溯附录（重要结论）
- 审查后修正（如有）

### 4.2 追溯附录

只在有重要结论时附。格式见 `traceability.md`。不必给每句话编号；只给会改变判断的主张。

如果追溯表里很多「未核验」，这是有价值的诚实，不是失败。不要为了表格好看而补来源。

### 4.3 审查记录

深度模式可以写：

```
审查后修正：初稿把「相关」写成「导致」；已改为「相关，因果方向未定」，并把证据状态从「强证据」降为「中等证据」。
```

只写实际修改。没有修改就写「审查通过，无需修正」，不要编造。

### 4.4 分轮

内容超过单轮承载时，可以分轮：

- 每轮说明覆盖哪些阶段/问题。
- 明确还剩什么。
- 不假装写完。
- 下一轮沿用已建立的编号与结论，不重复铺陈。

## 5. 不写什么

- 不写「众所周知」「显而易见」「本质上」来跳过论证。
- 不写「从哲学、经济学、社会学、心理学看」这种学科排比。
- 不写「一方面……另一方面……」却不说明证据差距。
- 不写「每个人情况不同」「事物都有两面性」作为结论。
- 不写「科学研究表明」而没有来源。
- 不写「你可能存在确认偏误」等人格标签。
- 不写「由于篇幅限制」；直接说没覆盖什么。
- 不写「希望对你有帮助」等填充语。

## 6. 长度

长度由内容决定：

- 快速：通常一两段，按内容决定。
- 标准：按内容决定，不设字数。
- 深度：可能长，也可能短；取决于证据和争议，不设下限。

**不要用字数证明深度。** 如果删掉一段不损失信息，就删。

## 7. 承认不知道

允许并且鼓励写：

- 「这一点我没有可靠来源。」
- 「现有证据无法区分 A 与 B。」
- 「这取决于你重视哪个价值，证据不能替你选。」
- 「我不知道这个数字；要回答需要查 X。」
- 「我的判断在 Y 条件下会改变。」

不要用模糊词掩盖：

- 坏：「可能有影响，也可能没有，因人而异。」
- 好：「在 X 条件下，影响方向可能是正的；没有 X 时，证据不足。」

## 8. 模式切换

- 用户说「太长了」→ 压缩，不删关键限定；先给结论。
- 用户说「展开」→ 补机制、竞争解释、追溯；不要只加形容词。
- 用户说「只给结论」→ 给结论 + 一句最强限定；不附完整追溯，但标明不确定性。
- 用户说「给我来源」→ 给来源表；不能核实的标未核验，不编链接。
- 用户说「你确定吗」→ 回到证据层，重新审查；不要只提高或降低语气。

## 9. 输出前最后一眼

1. 第一段是否直接回答了问题？
2. 有没有一个段落可以删掉而不损失信息？
3. 每个学科名后面是否都有具体工具/变量？
4. 有没有把价值判断写成事实？
5. 有没有把相关写成因果？
6. 重要结论能否追溯到事实与来源？
7. 盲点是否有证据，是否零条也敢写？
8. 是否有一句「什么条件下我会改判」？
