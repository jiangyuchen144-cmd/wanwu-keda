# 机制、竞争解释与反证

## 1. 机制分析

### 1.1 从「因为」到「经过什么」

「X 导致 Y」不是解释，只是结论。机制分析要写出中间环节：

```
X → M1 → M2 → Y
```

每一步问：

- 谁/什么在行动？
- 什么条件必须成立？
- 有没有可观测的中间结果？
- 时间多长？效应多大？
- 有没有反馈、阈值、滞后？
- 在什么范围内成立？

### 1.2 机制类型

| 类型 | 例子 | 证据要求 |
| --- | --- | --- |
| 物理/生物 | 温度影响酶活性 | 实验、剂量反应、机制研究 |
| 经济/激励 | 价格上升降低需求 | 需求弹性、自然实验、行为数据 |
| 制度/规则 | 产权界定影响投资 | 比较制度、断点、历史自然实验 |
| 心理/认知 | 即时奖励影响选择 | 实验、行为测量、复制证据 |
| 社会/网络 | 同伴影响改变行为 | 纵向数据、网络结构、工具变量 |
| 信息/信号 | 学历向雇主传递能力 | 信号模型、工资回归、对比群体 |

机制类型不决定结论强度。一个漂亮的心理机制故事，如果没有实验或行为证据，仍然是弱证据。

### 1.3 必要、充分、贡献

- **必要**：没有它，Y 不会发生（但可能有其他原因）。
- **充分**：有它，Y 一定发生（现实中很少）。
- **贡献**：它是多个原因之一，增加 Y 的概率或幅度。

不要把「贡献」写成「导致」，不要把「必要」写成「充分」，不要把「在样本中」写成「普遍」。

### 1.4 量级与时间

- 效应是 1% 还是 50%？没有量级的因果主张无法指导决策。
- 短期与长期可能反向：短期裁员、长期效率提升。
- 阈值与饱和：超过某点后机制失效。
- 反馈：A 影响 B，B 又反过来影响 A；线性外推会错。

## 2. 竞争性解释

### 2.1 生成解释

对同一组事实，至少尝试以下角度（不必全用）：

1. **反向因果**：Y 导致 X？
2. **共同原因**：Z 同时导致 X 和 Y？
3. **选择效应**：处理组本来就不一样？
4. **测量/定义**：相关是定义或口径造出来的？
5. **偶然/基础率**：在足够多的比较中，这个结果不奇怪？
6. **更简单的解释**：不需要额外假设的解释？
7. **问题本身有错**：前提、概念或范围不成立？
8. **价值框架不同**：事实相同，评价标准不同？

### 2.2 解释卡

只对重要解释写：

```
E1｜解释名称
- 核心主张：
- 它预测什么：
- 竞争解释预测什么：
- 什么观察能区分：
- 什么会削弱它：
- 什么证据足以放弃：
- 适用条件：
```

### 2.3 区分性观察

「区分性观察」必须是两个解释预测不同的地方。例子：

- 如果 E1（污染导致疾病）成立，搬到清洁水源的同一人群发病率应下降；如果 E2（年龄结构）成立，搬迁后不应下降。
- 如果 E1（自动化替代）成立，常规任务岗位应减少；如果 E2（需求扩张）成立，同一职业的就业可能增加。
- 如果 E1（制度导致增长）成立，制度变化后投资应上升；如果 E2（地理）成立，制度变化不应改变地理约束。

如果所有可观测结果在两个解释下都一样，它们目前不可区分。承认这一点。

### 2.4 证据差距，不是伪平衡

不要写「A 有道理，B 也有道理」就结束。要写：

- A 的证据类型、数量、独立性、复制情况。
- B 的证据类型、数量、独立性、复制情况。
- 哪一方依赖更强的额外假设。
- 哪一方能解释更多事实。
- 还缺什么关键观察。

## 3. 反事实

### 3.1 反事实问题

- 如果 X 没有发生，Y 会怎样？
- 如果 X 发生但机制 M 被阻断，Y 会怎样？
- 如果换成另一个群体/时间/制度，结论还成立吗？
- 如果观察到的只是选择效应，结果会怎样？

### 3.2 反事实不是想象

反事实需要比较基准。常见方法：

- 随机对照试验：处理组 vs 对照组。
- 自然实验：政策断点、冲击、工具变量。
- 双重差分：处理前后、处理组与对照组。
- 断点回归：阈值附近的比较。
- 匹配/加权：让组间可比。
- 机制检验：中介、安慰剂、排除性检验。

没有识别策略时，反事实只能是假设，不能当证据。

### 3.3 反事实的边界

- 不能观测到「同一个体同时接受和不接受处理」；因果推断依赖假设。
- 外推需要说明相似性：人群、制度、时间、剂量。
- 反事实分析不是「如果当初……就好了」的叙事；它要有可比较的基准。

## 4. 可证伪性

### 4.1 五个问题

对每个重要判断：

1. 这个判断预测什么？
2. 竞争解释预测什么？
3. 哪些观察能区分？
4. 什么结果会削弱它？
5. 什么证据足以让我放弃？

### 4.2 放弃条件

好的放弃条件是可观察的，不是「如果证据不足」。例如：

- 「如果控制基线后，处理组与对照组的就业变化无差异，我就放弃『政策提高就业』。」
- 「如果搬迁后发病率不下降，我就放弃『水源污染』的主要解释。」
- 「如果制度变化后投资没有上升，且地理变量仍能解释差异，我就降低『制度决定』的权重。」

### 4.3 不可证伪的主张

有些主张（部分价值判断、形而上学命题、定义性陈述）本来就不以可证伪为标准。不要因此说它们「错」；要标出它们属于哪类：

- 价值判断：用一致性、后果、价值前提来讨论，不用实验证伪。
- 定义：用清晰性、用法、后果来讨论。
- 经验主张：应能说出什么观察会改变它；说不出来，至少标「弱证据/待检验」。

### 4.4 证伪不是确认

「没有被证伪」不等于「被证实」。大量观察与预测一致，可能只是理论灵活或证据选择性。要看：

- 预测是否冒险（是否可能失败）。
- 是否有独立复制。
- 是否有竞争解释被排除。
- 理论是否在事后修改以适应证据。

## 5. 无法区分时

明确写：

> E1 与 E2 对现有事实的解释力相当；要区分，需要观察 X。现有证据不足以让我选一个。若必须行动，我会按代价/可逆性选择，而不是宣称某个解释已被证明。

这不是回避。把不可区分说成已区分，才是错误。

## 6. 机制与价值的分离

- 机制分析回答「如果做 X，会发生什么」。
- 价值判断回答「应不应该承受这些后果」。
- 不能因为机制有效就推出应该做；也不能因为价值上反对就否认机制存在。

例子：某项政策可能提高效率（因果推断），但加剧不平等（事实/价值混合）。效率证据不能自动回答「是否值得」。

## 7. 最小检查

1. 我有没有把「因为」写成机制？
2. 每一环的条件、量级、时间尺度是什么？
3. 有没有至少一个竞争解释？
4. 竞争解释的预测与当前解释哪里不同？
5. 什么观察会让我放弃？
6. 我有没有把不可区分说成已区分？
7. 我有没有把机制有效当成价值上应该？
