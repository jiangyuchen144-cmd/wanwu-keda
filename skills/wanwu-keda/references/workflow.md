# 十阶段工作流细则

这不是十段输出模板，而是内部工作流。快速模式可以压缩为几个动作；标准模式留下关键判断；深度模式完整执行并保留可核对痕迹。

## 0. 模式门

先问三个问题：

1. **答错会不会造成实际损害？** 医疗、法律、财务、安全、政策判断 → 倾向深度。
2. **是否存在真实证据争议或价值冲突？** 有证据/指标争议 → 至少标准；价值冲突与事实、指标争议交织 → 深度；争议核心是价值且事实清楚 → 标准即可。
3. **问题是否简单到一句话能可靠回答？** 是 → 快速；不要因为「万物可答」四个字就展开。

模式是预算，不是身份。标准模式发现关键事实缺口，可以升级；深度模式发现答案其实稳定，可以降级并说明。

## 1. 问题输入

保留用户原话。不要一上来改写；先确认自己没有被问题里的措辞带着走。

记录：

- 原问题（可引用短句）
- 用户真正要的交付物：解释、预测、建议、判断、事实核对、决策框架
- 模式与理由（一句话）

## 2. 问题解构

### 2.1 问题类型

| 类型 | 问法 | 可答条件 | 常见冒充 |
| --- | --- | --- | --- |
| 事实 | 是不是／多少／何时 | 观测、数据、文件 | 用理论当观测 |
| 定义 | 算什么／指什么 | 约定、用法、法律定义 | 把定义分歧当事实分歧 |
| 因果 | 为什么／会不会导致 | 机制 + 排除替代解释 | 相关当因果 |
| 价值 | 该不该／好不好 | 价值前提 + 事实后果 | 用事实回答价值 |
| 政策 | 要不要做／怎么做 | 目标 + 手段有效性 + 代价分布 | 目标正确就证明手段有效 |
| 动机 | 他为什么这样做 | 行为证据 + 推断 | 心理诊断 |
| 身份/意义 | 我是谁／意义是什么 | 概念澄清 + 视角 + 价值 | 伪装成科学事实 |

混合问题必须拆。典型：「AI 会不会取代人类工作，我该选什么专业？」= 因果预测 + 个人决策 + 价值偏好。三部分不能用一句话一起答。

### 2.2 隐含前提

把问句改写成陈述句，找出它已经接受的东西：

- 存在预设：「为什么富人越来越富」预设了「富人越来越富」。
- 因果预设：「游戏为什么让人上瘾」预设了游戏是原因。
- 范围预设：「中国人都怎么想」预设了一个可谈论的整体。
- 评价预设：「怎么才能不被淘汰」预设了淘汰是必须接受的规则。
- 定义预设：「自由是不是比安全重要」预设两者可通约比较。

每个前提标：**有证据支持／未检验／明显错误／价值选择**。前提错了，后面全改；不要把错误前提当地基。

### 2.3 问题契约

用三五句话写清：

- 我理解的问题是什么
- 哪些部分可答，哪些不可答
- 我暂时接受哪些前提
- 我还缺什么信息

不要写成长篇复述。标准模式可以只写一句「这题真正问的是 X，不是 Y」。

## 3. 基础事实提取

先找承重事实，不先找学科。

### 3.1 什么算承重事实

如果这条事实为假，结论会改变，它就是承重的。典型：

- 量化数据、时间、适用范围
- 法律条文、判决、官方定义
- 关键机制的存在与否
- 反例、失败案例、异常观测
- 竞争解释所依赖的事实

背景介绍、常识定义、过渡性说明不算承重事实，不需要完整追溯。

### 3.2 事实卡

每条承重事实至少写：

```
F1｜事实陈述
- 资料类型：观测／测量／文件／判决／统计
- 时间/地点/范围：
- 证据状态：已核实／强证据／中等证据／弱证据／未知
- 来源：S1（或「记忆，未核验」）
- 如果它为假，结论怎么变：
```

不要把「理论解释」写成事实卡。理论是解释框架，不是观测。

### 3.3 事实缺口

明确列出：

- 我找不到的数据
- 来源冲突的地方
- 只能靠类推的地方
- 用户未提供、但会改变结论的信息

事实缺口不是免责声明，它要影响结论的确定性和建议。

## 4. 知识领域选择

### 4.1 选择规则

从问题出发，不从矩阵出发。依次问：

1. 这个问题里，哪个词需要被某个领域定义？
2. 哪个领域提供硬约束（物理、生物、统计、法律、预算）？
3. 哪个领域提供关键变量或机制？
4. 哪个领域提供反例、比较案例或另一种解释？

四条都没有答案 → 不选领域。纯逻辑、纯定义、纯价值澄清经常如此。

### 4.2 选择记录

每个领域一行：

```
领域 → 提供的具体工具/变量/约束 → 它不能回答什么
```

例子：

```
劳动经济学 → 任务模型：区分替代任务与互补任务 → 不能判断个人该不该转行
伦理学 → 价值冲突结构：自由与保障的取舍 → 不能预测政策效果
```

只写学科名不算选择。写不出「它具体提供什么」，就删掉。

### 4.3 数量

- 0 个：合法。
- 1 个：常见且优先。
- 2～3 个：每个都带来不同工具或变量。
- 更多：必须有明确分工；否则是覆盖面表演。

不设「至少三个学科」的规则。矩阵外领域允许使用；写清它提供什么，不虚构学派或人名。

### 4.4 禁止

- 默认遍历 31 个学科或 44 个矩阵格。
- 为了「全面」把无关领域写进来。
- 用学科名称替代分析。
- 把同一工具换三个学科名重复计算。
- 因为矩阵里没有，就拒绝一个有用的领域。

## 5. 机制分析

### 5.1 机制链

把「X 导致 Y」展开成可检查的中间环节：

```
X → M1 → M2 → Y
```

每一环问：

- 这个环节需要什么条件？
- 有没有经验证据支持这一环？
- 时间尺度多长？
- 效应量级多大？
- 有没有反馈回路或阈值？
- 在什么范围内成立，越界后怎么失效？

### 5.2 必要与充分

- 必要机制：没有它，结果不会发生。
- 充分机制：有它，结果是否一定发生？
- **贡献性**：它只是若干原因之一。

不要把「有助于」写成「导致」，不要把「必要」写成「充分」。

### 5.3 机制不是故事

一个漂亮的故事不是机制证据。机制至少要有：

- 可识别的行动者或变量
- 可观测的中间结果
- 能失败的预测
- 与竞争机制区分开的含义

## 6. 竞争性解释

### 6.1 从哪找

- 反向因果：Y 导致 X？
- 共同原因：Z 同时导致 X 和 Y？
- 选择效应：样本自己选择了处理？
- 测量/定义：相关是定义造出来的？
- 更简单的解释：不需要额外假设的解释？
- 「这不是一个真问题」：前提或概念本身有问题？
- 另一种价值框架：事实相同，评价标准不同？

### 6.2 解释表

只对重要解释填，不要求凑数：

| 解释 | 核心主张 | 它预测什么 | 竞争解释预测什么 | 区分性观察 | 什么会削弱它 | 何时放弃 |
| --- | --- | --- | --- | --- | --- | --- |
| E1 | … | … | … | … | … | … |
| E2 | … | … | … | … | … | … |

「区分性观察」必须是两者预测不同的观察。如果两个解释对所有可观测结果预测相同，它们目前不可区分。

### 6.3 证据差距

不搞伪平衡。用差距表述：

- 「A 有随机试验和独立复制，B 只有个案与机制推测——不是势均力敌。」
- 「两者证据相当，但 B 依赖更强的额外假设。」
- 「现有证据无法区分，因为缺少 X 类观测。」

## 7. 反证检验

### 7.1 五个问题

1. 当前解释预测什么？
2. 竞争解释预测什么？
3. 哪些观察能区分它们？
4. 什么结果会削弱当前解释？
5. 什么证据足以让我放弃当前判断？

### 7.2 反证不是举例

「也有人不同意」不是反证。反证必须是：

- 一个具体观察或数据
- 一个会违反当前预测的结果
- 一个机制上说不通的地方
- 一个能解释同样事实但更简单的竞争解释

### 7.3 无法区分时

明确写：

> 现有证据无法在 E1 与 E2 之间区分；要区分，需要观察 X。在拿到 X 之前，我不选一个「更合理」的答案。

这不是软弱，是校准。

## 8. 认知盲点审计

见 `blindspots.md`。核心纪律：

- 盲点不是冷知识。
- 四态：已识别／有依据的推断／待验证假设／不适用。
- 每条五项：隐含前提、缺失事实、错误位置、对结论影响、检验方式。
- 零条合法；禁止心理诊断；禁止为了完成任务制造盲点。

## 9. 综合结论

结论分层，不要混成一段：

1. **可以确定的**：事实、定义、已核实的约束。
2. **有条件的判断**：在什么条件下、多大程度上成立。
3. **仍有争议的**：竞争解释与证据差距。
4. **价值选择**：哪些是目标、权重、代价承受，不能由证据裁决。
5. **不知道的**：缺什么信息，拿到后怎么改判。

最后写一句「这个结论在什么条件下会改变」。不要用「总之，事物都有两面性」收尾。

## 10. 独立审查

见 `review.md`。审查必须在结论写完后另起一次，不以「我已经想过」代替。发现问题就改答案；改不动就降级或标注未解决。

## 快速路径

不是「跳过一切」，而是压缩：

1. 识别问题类型与前提（一两句）。
2. 给答案。
3. 给一条最关键依据与适用条件。
4. 只在确有重大隐含前提时提一句盲点。
5. 结束。不列学科，不建追溯附录，不写固定角度排比。

快速模式若发现关键事实不确定，直接说「这一点我不确定」，不要用深度结构掩盖。

## 深度路径的检查点

- 阶段 3 之后：有没有承重事实是「记忆，未核验」？有 → 检索或降级。
- 阶段 4 之后：每个领域是否都提供了不同工具？没有 → 删。
- 阶段 6 之后：竞争解释是否真的可区分？不可区分 → 明说。
- 阶段 8 之后：盲点是否有证据等级？没有 → 降为待验证或删。
- 阶段 10 之后：审查是否真的改了东西？没有 → 说明审查通过，不要伪造修改记录。

## 停止与回退

- 如果新事实推翻了问题前提，回到阶段 2。
- 如果机制链断裂，回到阶段 3 或降低结论强度。
- 如果竞争解释无法区分，停在「无法区分」，不要硬选。
- 如果剩余分歧是价值，停止用证据争论，交给用户。
- 如果继续分析不改变判断，停止。
