# 评估与测试规范

本文件用于判断 Skill 是否真正帮助用户发现原本未意识到的问题。评价对象是实际输出与交互，不是提示词写得是否宏大。

## 1. 核心评价问题

最高评价标准：

**用户经过探索后，是否看见了探索前看不见的重要问题，并且更准确地知道自己知道什么、不知道什么？**

不要把篇幅、术语数量、学科数量或引用数量当成主要质量指标。

## 2. 评分维度

每项按 0–4 分评分：

- **0：缺失或明显失败**
- **1：有提及，但浅显、机械或不准确**
- **2：基本完成，但存在重要遗漏**
- **3：完成良好，依据和边界清楚**
- **4：表现突出，带来实质性认知增量**

| 维度 | 评估问题 |
|---|---|
| 问题理解 | 是否准确识别用户真正的问题？ |
| 前提审查 | 是否发现关键隐藏前提或概念歧义？ |
| 问题扩展 | 是否提出用户未想到且真正重要的新问题？ |
| 变量识别 | 是否找到可能改变结论的关键变量？ |
| 机制解释 | 是否解释变量如何产生结果，而非只列因素？ |
| 理论比较 | 是否呈现有解释力的竞争理论及其差异？ |
| 证据质量 | 是否区分事实、推断、假说和价值判断？ |
| 反证能力 | 是否主动寻找反例及可区分理论的证据？ |
| 交互质量 | 提问是否有目的、适量，并提供足够背景？ |
| 不确定性 | 是否诚实说明未知、争议和核验限制？ |
| 收敛能力 | 是否能聚焦高价值方向，避免无意义发散？ |
| 认知增量 | 用户是否获得了新的理解或更好的问题框架？ |

满分 48 分。分数只用于比较版本和定位缺陷，不应被当成客观科学测量。

## 3. 必测问题集

### 测试 A：人为什么贫穷？
考察：
- 贫穷定义是否被拆解；
- 是否区分收入、财富、消费能力和能力；
- 是否识别个人、家庭、市场、制度等层级；
- 是否避免把相关性直接当成因果；
- 是否提出能够区分竞争解释的证据。

### 测试 B：什么是自由？
考察：
- 是否区分消极自由、积极自由及其他概念；
- 是否识别自由与安全、平等、秩序之间的价值冲突；
- 是否避免把某一哲学传统当成唯一答案；
- 是否区分概念分析与现实制度评价。

### 测试 C：AI 会不会取代人类？
考察：
- 是否区分任务替代、岗位替代和职业结构变化；
- 是否识别技术、成本、组织、制度和需求变量；
- 是否区分短期预测与长期预测；
- 是否表达不确定性并指出可观察指标。

### 测试 D：股票为什么会上涨？
考察：
- 是否区分价格、价值、预期和流动性；
- 是否考虑供需、现金流、利率、风险偏好和信息变化；
- 是否避免单因果解释；
- 是否区分短期价格波动与长期回报。

### 测试 E：我应该如何度过人生？
考察：
- 是否区分事实问题、价值问题和个人选择；
- 是否避免替用户擅自指定人生目标；
- 是否识别约束、偏好、责任和机会成本；
- 是否通过适当提问帮助用户澄清目标。

## 4. 失败类型标签

测试失败时，至少标注一个主要原因：

- `OVERLISTING`：罗列角度或理论，缺少关系和筛选。
- `PREMISE_MISS`：没有检查问题隐藏前提。
- `CONCEPT_COLLAPSE`：混淆定义、指标和现象。
- `CAUSAL_LEAP`：因果跳跃或忽略混杂变量。
- `FALSE_BALANCE`：把证据强弱悬殊的观点写成势均力敌。
- `NO_COUNTEREVIDENCE`：只找支持材料，没有反证。
- `HALLUCINATED_SOURCE`：来源、数据或引文不真实。
- `QUESTION_DUMP`：把大量问题推给用户。
- `USER_BURDEN`：让用户承担本应由 AI 完成的研究。
- `NO_CONVERGENCE`：持续发散，没有聚焦关键问题。
- `FORCED_CONCLUSION`：证据不足仍强行给出确定结论。
- `NO_COGNITIVE_GAIN`：内容很多，但没有让用户看到新的重要问题。

## 5. 版本对比方法

比较两个版本时：
1. 使用相同模型、相同用户输入和尽可能相同的工具条件。
2. 保留完整对话，不只比较第一轮答案。
3. 分别评分，并记录具体文本证据。
4. 记录用户是否提出了新的问题、修正了判断或发现了遗漏。
5. 不因新版本更长、更专业或格式更漂亮就判定它更好。
6. 至少在五个不同类型的问题上测试后，再决定是否保留架构调整。

## 6. 回归测试

每次修改 Skill 后，重新运行至少三个基准问题：
- 人为什么贫穷？
- 什么是自由？
- AI 会不会取代人类？

检查新修改是否改善目标能力，同时没有导致：
- 简单问题也被过度复杂化；
- 每轮都机械提问；
- 不必要的跨学科扩张；
- 事实核验能力下降；
- 用户无法获得直接答案。
