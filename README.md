# wanwu-keda（万物可答）

把问题拆到可靠的事实和判断上。不是回答一切，而是让 AI 尽可能准确地说清：**它知道什么、不知道什么、可能在哪里错**。

## 它解决什么

用户抛出问题时，往往还没想清自己到底在问什么。单一学科的直接回答等于替用户预设了问题的形状。本 Skill 先检查问题本身，再给事实、证据与解释，并让盲点可被检验。

七个具体问题：

1. 你是否正确理解了自己提出的问题？
2. 提问里有没有未经证明的前提？
3. 是否遗漏了关键事实和变量？
4. 是否存在其他更合理的解释？
5. 当前结论有多少证据支持？
6. 哪些问题仍然无法确定？
7. 你是否在用错误的概念、方法或推理方式思考？

## 架构

**三个档位**：直答（1～2 段）／标准（4～6 模块）／深度（8～10 模块）。档位由问题决定，不由格式决定。简单问题不会被拆成十段。

**四个引擎**

| 引擎 | 做什么 |
| --- | --- |
| 问题解构 | 拆词、辨语境、判类型、拆混合问题、提取隐含前提、识别错误预设、必要时重构问题 |
| 知识与事实 | 按需选学科、取基础事实、建立关系、区分相关与因果、追溯依赖 |
| 竞争性推理 | 找竞争解释、给最强支持与最强反驳、反例、反事实、适用条件、推翻条件 |
| 认知盲点审计 | 前提／概念／事实／因果／视角／方法／价值七类盲点，每条附检验动作 |

**三维证据标注**：信息性质（事实／定义／推断／理论／价值判断）× 证据状态（已核实／强／中／弱／未知）× 推理类型（演绎／归纳／溯因／类比／概率推断）。

**可扩展学科矩阵**：44 格，其中 13 格方法型学科（统计与概率、因果推断、信息论、系统科学、复杂性、博弈论、决策科学、控制论、计算机与 AI、科学哲学、公共政策、制度分析、风险管理）。矩阵是索引不是边界，允许按问题新增领域。

**五级知识结构**：原始观察 → 基础事实 → 关系与机制 → 理论与解释 → 判断与价值。「最小基本事实」是依赖研究目标的分析单位，不宣称绝对不可再分。

## 防理性幻觉

十道红线：不拿学科数量造全面感、不拿专家名字造权威感、不用术语掩盖事实不足、不用伪平衡掩盖证据差距、不用因果故事代替因果证据、不把推测当事实、不把相关当因果、不把价值当规律、不给用户做心理诊断、不为填结构生产内容。

允许说「目前无法知道」，允许指出问题本身有错，允许承认自己的分析有局限。

## 安装

```bash
npx -y skills add jiangyuchen144-cmd/wanwu-keda -g --all
```

## 使用

说「万物可答」或直接提问：

> 人为什么会贫穷？
> 人工智能会不会取代人类工作？
> 为什么我明明知道该学习，却总是去玩游戏？

需要更细时说「深挖因果推断」「给我证据状态」「只给结论」。

## 边界

不替用户做价值决定；高风险领域（医疗、法律、金融）给框架与证据状态，不做个体化诊断；不虚构论文、专家、数据与案例；不帮撒谎、不提供伤害他人的方案。

## 依赖与隐私

纯文本技能，无脚本、无数据收集。是否联网由问题需要决定：涉及政策、价格、法规、技术能力等时效性事实时会核查并标日期。
