# wanwu-keda（万物可答）v3

把问题拆到可靠的事实和判断上。不是回答一切，而是让 AI 尽可能准确地说清：**它知道什么、不知道什么、可能在哪里错**。

v3 的重点不是增加学科、理论或案例，而是修复分析架构：不再默认遍历学科，不再强制固定输出，不再用格式制造全面感；重要结论必须能追溯到事实与来源，回答生成后必须独立审查。

## 它解决什么

1. 用户是否正确理解了自己提出的问题？
2. 提问里有没有未经检验的前提？
3. 是否遗漏了关键事实和变量？
4. 是否存在其他更合理的解释？
5. 当前结论有多少证据支持，能否追溯？
6. 哪些问题仍然无法确定？
7. 是否在用错误的概念、方法或推理方式思考？

## 架构

```
问题输入
  → 问题解构
  → 基础事实提取
  → 知识领域选择（0～n，按需）
  → 机制分析
  → 竞争性解释
  → 反证检验
  → 认知盲点审计
  → 综合结论
  → 独立审查
```

**模式由问题决定**：快速（直接答）／标准（关键事实、机制、真实盲点、结论）／深度（完整流程 + 追溯 + 审查）。不设固定模块数、字数、盲点数或学科数。

**学科矩阵是检索工具，不是流程**：31 个学科 + 13 个方法领域，共 44 格。可以选 0 个、1 个或多个；允许矩阵外领域；只为「提供了不同工具/变量/硬约束」的领域付费。

**三维证据**：

- 信息性质：事实／定义／经验关系／因果推断／理论解释／价值判断
- 证据状态：已核实／强证据／中等证据／弱证据／未知
- 推理方式：演绎／归纳／溯因／类比／概率推断

证据状态不适用于价值判断本身；复合主张要拆开标。

**追溯链**：

```
结论 → 推理 → 依赖假设 → 基础事实 → 证据来源
```

重要事实、因果判断、量化结论和建议必须尽量可追溯；追溯不完整就下调可信度。

**盲点审计四态**：已识别／有依据的推断／待验证假设／不适用。零条合法；禁止把冷知识当盲点，禁止心理诊断。

**独立审查十项**：事实、来源、推理、隐藏假设、因果错误、遗漏解释、确定性、伪盲点、无关学科、结论越界。发现问题就改答案，不只加免责声明。

## 与 v2 的关键差异

| 维度 | v2（HEAD abb8bfb） | v3 |
| --- | --- | --- |
| 分析流程 | 四引擎，按需调用，无固定顺序 | 十阶段显式流程，含回退与审查 |
| 学科 | 动态选择，但输出模块仍要求 3～6 个学科 | 0～n；每个领域必须说明提供什么；允许矩阵外 |
| 输出 | 标准 4～6 模块 / 800～1800 字；深度 8～10 模块 / 2500～5000 字 | 无固定模块数、字数、盲点数；按需组装 |
| 盲点 | 七类，2～5 条 | 四态，0 条合法；五字段；反心理诊断 |
| 追溯 | 原则性要求 | 结论卡、ID、来源表、追溯状态与降级规则 |
| 来源 | 有分级与联网规则，缺结构化字段 | 名称/链接/日期/方法/发现/局限/支持主张；检索决策协议 |
| 审查 | 无独立流程 | 十项独立审查 + 修正协议 |
| 学科矩阵 | 44 格，部分理论/案例未逐条核验 | 31+13 格；修正错误；24 张理论卡；标明争议与线索 |

完整的实际 diff 见 `docs/v3-report.md`；facets 的逐条准确性修正见 `docs/facets-accuracy-audit.md`。

## 九个真实测试

`tests/outputs/` 保存九个问题的实际生成结果；`tests/reviews/` 保存独立审查记录；`tests/test-report.md` 汇总通过/失败情况。测试暴露的失败案例也写在报告里，不只展示成功。

测试问题：

1. 1+1 为什么等于 2？
2. 我是谁？
3. 人为什么会贫穷？
4. 人工智能会不会取代人类工作？
5. 民主制度是否优于其他制度？
6. 我应该追求财富还是自由？
7. 为什么我明明知道应该学习，却总是去玩游戏？
8. 一个人如何判断自己相信的东西是真的？
9. 如果所有人都相信一个错误的事实，它会不会变成真理？

## 静态完整性检查

```bash
python3 scripts/check_skill.py
```

检查内部引用是否断链、44 格/24 卡是否齐全、技能文件是否重新引入固定模块/字数配额。它不评价生成答案的质量。

## 安装

```bash
npx -y skills add jiangyuchen144-cmd/wanwu-keda -g --all
```

## 使用

说「万物可答」或直接提问：

> 人为什么会贫穷？
> 人工智能会不会取代人类工作？
> 为什么我明明知道该学习，却总是去玩游戏？

需要更细时说「深挖因果推断」「给我证据状态」「只给结论」「用深度模式」。

## 边界

不替用户做价值决定；高风险领域（医疗、法律、金融）给框架与证据状态，不做个体化诊断；不虚构论文、专家、数据与案例；不帮撒谎、不提供伤害他人的方案。

## 依赖与隐私

技能本身是纯文本提示词；仓库附带的 `scripts/check_skill.py` 只做本地静态完整性检查，不调用模型、不收集数据。是否联网由问题需要决定：涉及法律、医学、科技、金融、政治、统计数据等时效性事实时主动核验并标日期；无法核验时明确标注。
