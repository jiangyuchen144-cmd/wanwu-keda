# wanwu-keda（万物可答）v4

一个以**认知盲点发现**为核心的通用认知探索 Skill。目标不是给出更多内容，而是帮助用户看见探索之前看不见的问题，并更准确地知道自己知道什么、不知道什么。

## 核心能力

- 审查问题本身：概念、隐含前提、错误二分、事实／因果／价值混淆。
- 主动扩展问题空间：关键变量、观察尺度、利益相关者、反例、竞争解释。
- 建立知识与事实基础：区分观察、事实、定义、理论、推断、假说和价值判断。
- 比较竞争性解释：不仅列理论，还比较机制、前提、证据、适用范围和可检验预测。
- 审计七类盲点：前提、概念、事实、因果、视角、方法、价值。
- 自适应交互：独立研究、引导探索、混合探索；不把研究工作推回给用户。
- 允许没有最终结论；明确已知、未知、争议和核验限制。

## 安装

```bash
npx -y skills add jiangyuchen144-cmd/wanwu-keda -g --all
```

## 使用

说「万物可答」或直接提问：

> 人为什么会贫穷？
> 什么是自由？
> AI 会不会取代人类？
> 我应该如何度过人生？

简单问题直接回答；复杂问题才展开探索。

## 边界

- 不替用户做价值决定；给不同价值排序及其代价。
- 医疗、法律、金融等高风险问题给框架与证据状态，不做个体化诊断或操作指导。
- 不虚构研究、数据、来源、专家观点或引用。
- 不为了显得全面而制造争议、堆砌理论或强行发散。
