# wanwu-keda（万物可答）

把任何问题按 **领域 × 学派 × 理论 × 案例** 拆解，让认知盲点显形。哪怕「1+1」或「我是谁」这种看似简单、无厘头的问题，也像罗素对待 1+1=2 那样认真：先定义、再展开、最后标级。

## 解决的问题

用户抛出问题，往往自己还没想清真正想问的是什么。单一学科的直接回答，等于替用户预设了问题的形状。本 Skill 把问题摊成一张有层级的图，让用户在图上认出自己真正想问的那一句。

## 九段输出骨架

定档（这题能不能被证明）→ 字面拆解 → 类型判定 → 31 学科全景速览 → 深挖格（四件套：框架/学派/案例/盲点）→ 盲点清单 → 分歧地图 → 我不确定 → 真问题候选 → 续写指令。

每格、每条主张都挂三级标签：`证明`／`论证`／`推测`。拿不准就降级，不把推测伪装成论证。

## 安装

```bash
npx -y skills add jiangyuchen144-cmd/wanwu-keda -g --all
```

## 使用

对它说「万物可答」，或直接问一个模糊／跨学科／「该不该」类问题，例如：

> 我是谁？
> 我该不该辞职？
> 1+1 为什么等于 2？

想深入某一格就说「深挖物理」，想全部展开就说「全展开」，换认知基线就说「换基线」。

## 边界

- 不替用户下结论：价值分歧给出各方最强理由后，把选择权留给用户
- 不假装全知：「我不确定」是必写段
- 不提供伤害他人的操作指导

## 依赖与隐私

纯本地文本技能，无网络请求、无脚本、无数据收集。31 学科矩阵与案例锚均内置在 references 中。
