# wanwu-kewen（万物可问）

一个自主认知探索 Skill。它不只回答用户给出的问题，还审视问题、前提、规则、目标和需求本身，主动寻找用户与 AI 都尚未纳入认知范围的可能性、解释和反例。

## 核心原则

- 用户的问题是探索的入口，不是探索的边界。
- 不默认接受问题中的前提、目标与价值判断。
- 不把主流观点、现有规则或用户当前框架当作天然边界。
- 既挑战用户的认知，也挑战 AI 自己的判断。
- 区分事实、推断、假设、理论模型和思想实验。
- 简单问题直接回答；复杂问题才展开探索。
- 不为了形式完整而探索，也不为了尽快给出答案而提前结束。

## 使用

说「万物可问」，或直接提出需要重新审视、研究、解释、探索的问题：

> 人为什么贫穷？
> 什么是自由？
> AI 会不会取代人类？
> 我应该如何度过人生？

简单问题直接回答；复杂问题才进入自主探索。

## 边界

- 不替用户做价值决定，但会审视目标与价值前提。
- 医疗、法律、金融等高风险问题给框架与证据状态，不做个体化诊断或操作指导。
- 不虚构研究、数据、来源、专家观点或引用。
- 允许没有最终结论；明确已知、未知、争议与核验限制。
