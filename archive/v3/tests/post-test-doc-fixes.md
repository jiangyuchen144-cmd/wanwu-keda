# 测试后的文档一致性澄清

九题生成与审查针对 `tests/skill-hash-at-generation.txt` 的版本。之后做了一轮文档一致性清理，只修正会让人误读的表述，不改变分析流程、证据分级或输出规则：

1. 标准模式「工作重点」明确为按需，盲点可为 0。
2. 删除快速模式 1～2 段 / 1～4 段、标准字数区间的软配额。
3. 标准模式最小形态不再固定「两条事实 + 一个解释」。
4. 结论卡补齐六类信息性质、五级证据状态与推理方式。
5. 证据标注统一为 `[性质:… | 证据:… | 推理:…]`；删除「教科书共识」自造标签。
6. 事实卡「性质」改为「资料类型」，避免与信息性质同名异义。
7. 追溯表补齐信息性质、推理方式、失效条件等字段。
8. 模式门统一：价值冲突本身不自动升级，价值与事实/指标交织才深度。
9. 盲点定义补入「未检验的价值假设」。
10. 修正 facets 理论卡索引漏列的 E3/F11/E6 等领域。
11. 删除「十角度」旧词，改为「不写固定角度排比」。
12. 领域选择记录统一为箭头格式。

最终哈希见 `tests/skill-hash.txt`。这些修改未改变九题测试使用的核心规则；测试结果仍针对生成时版本，不能声称是在最终字节级版本上重新跑过。
