# 九个测试问题

生成时只使用问题本身，不附加预期模式或答案提示。

1. 1+1 为什么等于 2？
2. 我是谁？
3. 人为什么会贫穷？
4. 人工智能会不会取代人类工作？
5. 民主制度是否优于其他制度？
6. 我应该追求财富还是自由？
7. 为什么我明明知道应该学习，却总是去玩游戏？
8. 一个人如何判断自己相信的东西是真的？
9. 如果所有人都相信一个错误的事实，它会不会变成真理？

## 重点检查

| 题号 | 重点 |
| --- | --- |
| 1 | 简单问题是否被过度分析；是否用公理/定义而不是经验故事 |
| 2 | 是否区分「我是谁」的不同含义；是否假装有唯一科学答案 |
| 3 | 是否找到关键事实与机制；是否区分结构、文化与个人因素 |
| 4 | 是否给出条件性判断；是否把「任务可自动化」误推为「职业消失」 |
| 5 | 是否避免把不同制度按单一总分排序；是否区分评价指标与适用条件 |
| 6 | 是否识别价值冲突；是否假装存在客观唯一答案 |
| 7 | 是否仅凭描述做心理诊断；是否把机制写成待验证假设 |
| 8 | 是否区分真理与确证；是否承认有限理性与证言依赖 |
| 9 | 是否区分「事实为真」与「被普遍相信」；是否处理制度性事实的边界 |
