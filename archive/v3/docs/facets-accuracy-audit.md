## 3. 新增的理论卡

### 3.1 选择标准

不是矩阵里每个名字都升级成理论卡。满足以下至少两条的，才立卡：

1. 在多个领域或公共争论中反复出现；
2. 常被误用、误读或与邻近概念混淆；
3. 九个测试题直接需要；
4. 有可陈述的核心主张、假设、反驳与适用范围，而不是一个模糊口号。

未立卡的名字保留为 `[线索]`/`[争议]`，表示「检索起点，不等于已核实」。这是有意的取舍：宁可少写，不把未读过的文献伪装成完整卡片。

### 3.2 卡片清单

新增 `references/theory-cards.md`，24 张卡，覆盖九题直接涉及或最常被误用的理论：

T01 皮亚诺算术；T02 哥德尔；T03 人格同一性；T04 能力方法；T05 结构贫困；T06 任务模型；T07 多头政体/民主化；T08 价值多元；T09 双过程/自我控制；T10 时间贴现/习惯；T11 知识确证；T12 贝叶斯认识论；T13 证伪主义；T14 真理理论；T15 共识真理论/社会认识论；T16 从众；T17 因果推断；T18 GRADE；T19 人力资本；T20 贫困文化论；T21 IAD；T22 前景理论；T23 自我决定理论；T24 发展型国家/威权增长。

每卡包含：准确名称、提出者、核心主张、基本假设、支持证据、主要反驳、适用范围、当前学术地位、参考文献/检索线索。

## 4. 没有做的事（明确说明）

- 没有为 44 格中的每一个被提到的名字都建卡。矩阵里的很多名字仍是 `[线索]`。这不是「已经全部核实」。
- 没有逐篇打开理论卡引用的原始论文。卡片基于稳定的学术常识与可检索的文献线索；具体页码、DOI、最新研究状态仍需在正式引用前核对。
- 没有增加学科数量，也没有把矩阵扩展成百科全书。
- 没有把「当前学术地位」写成精确的文献计量结论；它是对争议状态的定性描述。

## 5. 仍存在的准确性风险

- 部分年份/版次可能因译本/再版而不同。
- 心理学复制率、营养研究、民主-增长文献都有更新；卡片给的是方向性描述，不是最新元分析。
- 理论卡的「支持证据」对规范理论只能是规范论证/测量实践，不能伪装成因果证据。
- 矩阵中未立卡的名字，可能在具体语境下需要更细的区分；使用时应查原始文献。
