「1+1=2」不是我们从数东西里总结出来的经验规律，而是通常的算术这套规则内部推出来的结果。

自然数是这样搭起来的：从 0 开始，每个数有唯一后继；1 是 0 的后继，2 是 1 的后继。加法定义为 a+0=a、a+S(b)=S(a+b)，代入 a=1、b=1，就得到：1+1 = 1+S(0) = S(1+0) = S(1) = 2。

所以「2」就是把「1 的后继」写成另一个符号，而 1+1 按规则算出来正好是 1 的后继。这是自然数公理（皮亚诺公理）里的一条定理，靠定义和演绎得到，不靠观察；公理本身是起点，不在系统内再被证明。现实里一个苹果加一个苹果得到两个，只说明这套算术在现实中好用，不是它的证明来源。

这句话只在通常的算术约定里成立：二进制里写作 1+1=10，在模 2 的算术里 1+1=0。所以「等于 2」是约定加公理的结果。如果你真正想问的是「数学是我们发明的还是发现的」，那是另一个问题。
