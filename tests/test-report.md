# 九题实测报告

## 0. 说明

本报告记录九个问题的**实际生成结果**、独立审查与人工来源抽查。生成与审查都由独立 agent 完成；原始稿、修正稿、审查记录均保留。

- 日期：2026-11-12
- 生成：每题一个独立 subagent，只给问题与 skill 路径，不提供预期答案
- 审查：另起一个未参与生成的 agent，按 `review.md` 十项检查
- 人工抽查：`tests/manual-source-check.md`
- 技能文件哈希：生成时 `tests/skill-hash-at-generation.txt`；最终 `tests/skill-hash.txt`。测试后只做文档一致性澄清，见 `tests/post-test-doc-fixes.md`。
- 原始稿：`tests/drafts/qN.md`
- 审查后答案：`tests/outputs/qN.md`
- 审查记录：`tests/reviews/qN.md`

**限制**：这是提示词技能的行为样本，不是确定性回归测试；同模型审查仍可能漏错；九题不覆盖所有领域。

## 2. 逐题记录

### q1 1+1 为什么等于 2

- **模式**：快速。生成 agent 判断这是定义清楚、答案稳定的基础数学题。
- **输出**：[q1.md](outputs/q1.md)
- **审查**：修改后通过；见 [q1 review](reviews/q1.md)。
- **实际发现的问题**：
  1. 初稿写「取 a=1、b=1」得到 1+1=S(1)，与推导链不符；正确是先把 1 写成 S(0)，再取 a=1、b=0。
  2. 初稿把二进制与模 2 并列，容易被读成「二进制里 1+1 不等于 2」。二进制只是记数法；模 2 是另一套代数结构。
- **是否过度分析**：没有。输出 3 段，未列学科、未做盲点、未附追溯表。
- **仍存风险**：只展示与本题相关的 PA 条款，未列归纳/递归定理与其余公理。

### q2 我是谁

- **模式**：标准。问题涉及身份/意义，需要概念澄清，但不是高风险事实题。
- **输出**：[q2.md](outputs/q2.md)
- **审查**：修改后通过；见 [q2 review](reviews/q2.md)。
- **实际发现的问题**：
  1. 初稿把「挑哪条人格同一性判据」整体说成价值选择，跳过了判据要受概念一致性与反例检验这一层。
  2. Parfit 的归属模糊（「甚至主张……可能」），未标明这是争议立场。
  3. 判据列表把「记忆」与「心理连续性」并列、未标非穷尽、缺「无我/束知觉」一路。
- **关键通过项**：没有假装知道用户资料；没有用神经科学或心理学给「我是谁」一个假唯一答案；没有心理诊断。
- **仍存风险**：未展开动物主义、法律同一性、叙事同一性与「我是哪种人」的区别。

### q3 人为什么会贫穷

- **模式**：标准。
- **输出**：[q3.md](outputs/q3.md)
- **审查**：修改后通过；见 [q3 review](reviews/q3.md)。
- **关键点**：三层「为什么」（个人/群体/国家）、三种贫困口径、结构/文化/个人解释、MTO/贫困陷阱/制度证据；区分解释贫穷与分配责任。
- **实际发现的问题**：
  1. 改判规则写反：原稿说「约束拉平后贫困仍由个人/文化解释→调高个人/文化；反之则调低结构」；后半句方向错了。审查改为「贫困随约束放松明显下降→调高结构」。
  2. 把「约束变化后行为变不变」当成区分结构与偏好的判决性检验；审查降为「线索」。
  3. 结尾「两边都说服不了对方」有伪平衡风险；改为「证据差距不对称，强版本贫困文化论支持最弱」。
  4. 「不知道」栏列了已知限制；审查拆成真正未知与已知边界。
- **来源**：世界银行、UNDP、Chetty 2016、Kraay & McKenzie 2014 链接与数字均经审查核对；MTO 的「券资格」与「实际搬家」区别已注明。
- **仍存风险**：结构解释的「证据相对较强」、强版本文化论「缺乏支持」是综述性判断，未逐项列来源；标准模式未加强制追溯表。

### q4 AI 会不会取代人类工作

- **模式**：标准（见失败案例；该题也可论证应为深度）。
- **输出**：[q4.md](outputs/q4.md)
- **审查**：修改后通过；见 [q4 review](reviews/q4.md)。
- **关键点**：任务/岗位/职业分层；Stanford Canaries 描述性证据；ILO 潜在暴露；Eloundou 任务暴露；Acemoglu 模型估计；替代/互补两种解释。
- **实际发现的问题**：初稿把「25-54 岁就业人口比」写成 71.9%，并链接到 20-24 岁劳动参与率序列 `LNS11300036`；审查与人工抽查均发现该错配，已改为 80.7 并换用 `LNS12300060`。见 `manual-source-check.md`。
- **其他修正**：补「同年龄段」限定 11%/10% 的样本；「总量」改「就业市场」；职业层删去「没有普遍证据」的过强说法，改为「没有『由 AI 导致职业整体消失』的普遍证据」；补「ADP 样本差距比全国调查基准更明显」的外推限制。

### q5 民主制度是否优于其他制度

- **模式**：深度。问题核心是「优」的评价标准冲突，且增长/治理证据冲突。
- **输出**：[q5.md](outputs/q5.md)
- **审查**：修改后通过；见 [q5 review](reviews/q5.md)。
- **关键点**：拆「民主」「其他制度」「优」；区分最低限度选举定义与自由宪政民主；五种评价标准；增长证据冲突；选择效应/反向因果/测量；价值选择归还用户。
- **实际发现的问题**：
  1. 初稿用「剩下的分歧是价值，不是数据」把增长效应量级的经验争议也归入价值，形成虚假二分。
  2. 关键结论只有来源列表，没有 C→R→A→F→S 追溯链；审查补了 3 条（C1 增长、C2 权力约束、C3 信息纠错）。
  3. 「Sen 的论证得到广泛支持」过度确定；改为「影响很大但有争议」。
  4. 魏玛「选出」希特勒不准确（兴登堡任命）；改为「把破坏民主的人送上台」。
  5. 「生态谬误」用于跨国平均推单个国家不准确；改为「层次谬误」。
- **关键通过项**：不把制度排成单一总分；民主/威权不是二元；增长证据冲突；价值权重交给用户；改判条件明确。
- **仍存风险**：「国家能力比政体标签更重要」「东亚发展型国家条件」未进追溯表；盲点只标了待验证，未展开五字段。

### q6 我应该追求财富还是自由

- **模式**：标准。
- **输出**：[q6.md](outputs/q6.md)
- **审查**：修改后通过；见 [q6 review](reviews/q6.md)。
- **关键点**：识别价值冲突，不假装唯一答案；拆自由层次；收入-幸福研究标为相关而非因果；三种价值排序及代价。
- **实际修正（从输出 diff 可见）**：
  1. 区分「日常情绪」与「生活评价」：75k 平台主要针对日常情绪，生活评价仍随收入上升。
  2. 补 Kahneman & Deaton 的数据年份（2008–2009）与「美国样本、观察性自报」限制。
  3. Killingsworth 等 2023 的平台限定为「最不幸福的那部分人（约最低 15%–20%）」。
  4. 补「收入是流量、不是资产存量」「相关不强」等口径提醒。
  5. 补政治/法律自由与个人生活自由的区别。
- **审查确认**：价值冲突处理充分；「财富是手段」被保留为一种框架而非事实；收入研究的相关性/外推限制已补。

### q7 为什么我明明知道应该学习，却总是去玩游戏

- **模式**：标准。
- **输出**：[q7.md](outputs/q7.md)
- **审查**：修改后通过；见 [q7 review](reviews/q7.md)。
- **实际发现的问题**：
  1. 初稿把「94 个独立检验」写成「94 项研究」，夸大了证据数量。
  2. 初稿把「你先用游戏把不舒服压下去」「情绪上更能止痛」写成对用户动机的事实断言，接近心理归因。
  3. 初稿默认「学习」是用户自己的目标，直到最后才质疑「应该」。
- **关键通过项**：修正后保留五种待验证解释；未诊断拖延症/ADHD/成瘾；把「应该」标为价值前提；转介专业人士不是诊断。
- **仍存风险**：社交/陪伴、睡眠不足、临床问题未单列；研究外推（拖延→游戏）已标为延伸。

### q8 一个人如何判断自己相信的东西是真的

- **模式**：标准。
- **输出**：[q8.md](outputs/q8.md)
- **审查**：修改后通过；见 [q8 review](reviews/q8.md)。
- **实际发现的问题**：
  1. 初稿把可证伪性说得过宽，未区分数学/逻辑命题。
  2. 未明说证言依赖与来源资质/利益冲突。
  3. 未把「不知道」列为合法终点。
  4. 「检验是整体性的」是理论立场，应加「往往」。
- **关键通过项**：区分真与确证；不把共识当真理；不把「有用」当「真」；承认背景信念不可全疑。
- **仍存风险**：「真=符合事实」是操作性约定，未为某种真理理论辩护；「后见之明偏差」未给具体文献。

### q9 如果所有人都相信一个错误的事实，它会不会变成真理

- **模式**：标准（按输出形态判断；生成 agent 未回传模式）。
- **输出**：[q9.md](outputs/q9.md)
- **审查**：修改后通过；见 [q9 review](reviews/q9.md)。
- **关键点**：共识不制造真理；制度性事实与自证预言的边界；不滑向相对主义；区分「被相信」与「为真」。
- **实际发现的问题**：
  1. 首段把「信念不改变真假」写成无条件结论，与后文制度性事实/自证预言例外冲突；审查加「对那些不会因为人信什么而改变的事实来说」。
  2. 总结段把制度性事实说成「原本为假、后来成真」，混淆「构成」与「因果」；审查拆开。
  3. 「它们在实验里有支持」把从众、重复效应、公开附和混成一档证据；审查按强弱分层，不补未核对文献。
  4. 「任何时代都有异见者」是不可核验的全称判断；改为「通常是」。
  5. 「事实的真假」是范畴错误；改为「说法的真假」。
- **关键通过项**：明确「共识是线索」；制度性事实只限制度领域，不推到自然事实；自证预言是行为造成；价值选择不替用户定。
- **仍存风险**：未补具体文献；制度性事实背后的国家强制/权力未展开；经验机制的社会尺度量级未给。

## 4. 失败案例汇总

1. **q1 推导参数错误 + 二进制/模 2 混淆**：审查修正。
2. **q2 把判据选择整体当价值选择 + Parfit 归属模糊**：审查修正。
3. **q4 指标/序列错配**：独立审查与人工抽查都发现；见 `reviews/q4.md` 与 `manual-source-check.md`。
4. **q7 统计口径错误 + 把机制写成用户事实**：审查修正。
5. **q8 可证伪性未分域 + 证言/不知道缺失**：审查补足。
6. **模式选择偏保守**：q4 是高风险/时效/争议题，却选了标准模式；答案质量尚可，但缺少完整追溯表。说明模式判据仍有模糊。

## 5. 未解决/未验证

- 独立审查由另一个 agent 完成，但仍是同一模型；不能保证发现所有错误。
- 技能是提示词，没有运行时强制；真实产品调用可能省略追溯/审查。
- 九题均完成独立审查并判定「修改后通过」；没有出现阻断后仍放行的案例。
- 测试后对规范做了一次文档一致性澄清；九题测试针对的是生成时版本，见 `post-test-doc-fixes.md`。
- 未覆盖医疗、法律、金融、安全等高风险场景。
- 未做跨模型对比；不同模型的执行差异未知。
- 理论卡与 facets 的文献未逐篇核对；见 `docs/facets-accuracy-audit.md`。
