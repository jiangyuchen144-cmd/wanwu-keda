在通常的算术里，1+1=2 的成立不依赖数苹果这类观察：它是由自然数的定义和公理演绎出来的定理。现实中的数数只说明这套算术适用，不是它的证明来源。

在皮亚诺公理下，自然数从 0 开始，每个数有唯一后继；1 是 0 的后继，2 是 1 的后继。加法由 a+0=a、a+S(b)=S(a+b) 递归定义。把 1 写成 S(0)，再在 a+S(b)=S(a+b) 中取 a=1、b=0，就有：1+1 = 1+S(0) = S(1+0) = S(1) = 2。

所以「2」只是「1 的后继」的记号；1+1=2 是在这组公理和定义下推出的定理，公理本身则是起点，不在系统内再被证明。换成二进制，2 记作 10，同一个事实写成 1+1=10（二进制）；若换一套代数结构，比如模 2 算术，1+1≡0（模 2 下 2 也等价于 0）——那是另一套规则，不是同一个等式被推翻。若你问的是「数学是发明的还是发现的」，那是另一个问题。
